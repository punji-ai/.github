- Developer docs: [punji.ai/developers](https://punji.ai/developers)
- Full API reference, also readable by LLM agents: [punji.ai/llms-api.md](https://punji.ai/llms-api.md)
- Data sources and methodology: [punji.ai/data-sources](https://punji.ai/data-sources)

## Punji Data API

Programmatic access to Indian mutual fund and stock market data: fund and stock lookup, returns, risk metrics, holdings, category leaderboards, AMC and fund-manager info, industry fund flows, and fund and stock comparison. Data comes from AMFI (mutual funds), NSE (stocks and indices) and BSE (indices) and is refreshed nightly. There is a free evaluation tier.
